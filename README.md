## 1. Project Description

This project is a personal portfolio website developed using HTML, CSS, and JavaScript. It is a continuation of Assignments 1 and 2, with additional advanced functionality to improve the website's interactivity, performance, and user experience.

The website contains four main sections: About Me, Projects, GitHub Repositories, and Contact.

### Main Features

- **GitHub API Integration:** Fetches and displays up to six recently updated public repositories from my GitHub account.
- **Project Filtering and Sorting:** Allows visitors to filter projects by category and sort them alphabetically.
- **Dark/Light Mode:** Allows users to switch between themes and saves their preference using localStorage.
- **Dynamic Greeting:** Displays a greeting based on the current time of day.
- **Contact Form Validation:** Checks user inputs and displays appropriate success or error messages.
- **Error Handling:** Displays a helpful message if GitHub repositories cannot be loaded.
- **Responsive Design:** Adapts the layout for desktop, tablet, and mobile devices.
- **Animations:** Includes smooth transitions and hover effects.

## 2. Technologies Used

- **HTML5:** Website structure and content.
- **CSS3:** Styling, responsive design, and animations.
- **JavaScript:** Dynamic content, filtering, sorting, API requests, and form validation.
- **GitHub REST API:** Retrieves public repository information.
- **localStorage:** Saves the user's theme preference.

## 3. Setup Instructions

To run the website locally:

1. Download or clone the GitHub repository.
2. Extract the ZIP file if downloaded.
3. Open the project folder in Visual Studio Code.
4. Open `index.html` using Live Server or a web browser.
5. Make sure you have an internet connection to load GitHub repository data.

No additional libraries or package installations are required.

## 4. How to Use the Website

Visitors can navigate between the About Me, Projects, GitHub Repositories, and Contact sections using the navigation bar.

In the Projects section, visitors can filter projects by category and sort them alphabetically.

The GitHub section automatically retrieves public repositories and displays their names, descriptions, programming languages, and repository links.

Visitors can also switch between light and dark mode. Their preference is saved and restored when they revisit the website.

The Contact section provides a form with input validation and confirmation messages. This is a front-end demonstration, so messages are not actually sent or stored.

## 5. Performance Optimization

The website uses lightweight HTML, CSS, and JavaScript without external frameworks.

The GitHub section displays a maximum of six repositories to keep the interface simple and reduce the number of rendered cards.

JavaScript functions are organized to avoid unnecessary repetition, and CSS media queries provide responsive layouts.
