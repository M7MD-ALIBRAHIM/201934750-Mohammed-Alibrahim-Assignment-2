Assignment 2 

1. Project Description:
In Assignment 2, I improved the website by adding the following features:

Project Filtering: Users can filter projects by category, such as Web Development and Games.

Dark/Light Mode: Users can switch between themes, and their preference is saved using localStorage.

Dynamic Greeting: The website displays a greeting based on the time of day.

Animations: Smooth transitions and hover effects improve the appearance of the website.

Contact Form Validation: The form checks user input and displays appropriate success or error messages.

The website is also responsive and designed to work on desktop, tablet, and mobile devices.

2. Setup Instructions

To run the website locally:

Download or clone the GitHub repository.

Extract the ZIP file if downloaded.

Open the project folder in Visual Studio Code.

Make sure the HTML, CSS, and JavaScript files are in their correct folders.

Open index.html in a web browser.
